# Hospital Management System

This is a basic Hospital Management System developed using Java and web technologies. It is designed to handle the workflow of a hospital environment with four key modules: Admin, Doctor, Receptionist, and Patient.

## Modules and Responsibilities

### 1. Admin Module
- Add/View Doctor Details
- Add/View Patient Details
- Add/View Receptionist Details
- View Appointment Details

### 2. Doctor Module
- View Patient Details
- View Appointment Details

### 3. Receptionist Module
- View Doctor Details
- View Patient Details
- Add Patient
- Add Appointment

### 4. Patient Module
- View Doctor Details
- View Appointment Details

## Features
- CRUD Operations (Create, Read, Update, Delete)
- Simple and clean user interface
- Background images and colors used for basic styling

## Technologies Used
- Java
- JavaScript (basic for interactivity)
- HTML/CSS
- MySQL (or other DB for backend)
- NetBeans (IDE used for development)

## How to Run the Project
1. Clone the repository.
2. Open the project in NetBeans IDE.
3. Make sure the database is configured properly.
4. Run the application and test all modules.
